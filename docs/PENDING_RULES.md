# Candlelight — Pending Rules Review Queue

**Status:** Provisional working document. **Not authoritative.**

This file is the mandatory review buffer for all newly proposed Candlelight rules, rulings, Keywords, Conditions, mechanics, corrections, and clarifications.

Nothing in this file is an established Candlelight rule until the user explicitly approves it for promotion into `docs/CANDLELIGHT_RULES.md`.

## Safeguard Rules

1. New or changed rules must be written here first.
2. Do **not** edit `docs/CANDLELIGHT_RULES.md` merely because a rule was discussed or appears settled in conversation.
3. The user must explicitly approve promotion of the pending rule.
4. After approval, copy the approved wording into the appropriate section of `docs/CANDLELIGHT_RULES.md`.
5. Once promoted, remove the entry from the active queue or move it to the short Promotion Log at the bottom of this file.
6. If a pending proposal conflicts with canonical rules, `docs/CANDLELIGHT_RULES.md` remains authoritative until promotion occurs.
7. Pending material must never be cited as an established rule when answering Candlelight rules questions.
